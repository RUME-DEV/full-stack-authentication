# Full Stack Authentication Application

A full-stack web application built with React, Node.js, Express, and MongoDB. The project demonstrates authentication, protected routes, and modern client-side routing.

## Features

- User registration and login
- JWT authentication using HTTP-only cookies
- Protected routes
- Guest-only routes
- Authentication state management with React Context
- Nested routes with React Router
- Client-server communication

## Tech Stack

### Frontend

- React
- React Router
- CSS Modules

### Backend

- Node.js
- Express.js
- MongoDB
- JWT
- HTTP-only Cookies
